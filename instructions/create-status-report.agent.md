# Create weekly status report

Generate a weekly status report from the work described in the request.

## Format

- Markdown
- Sections: Accomplishments, Blockers, Next week
- Bullet points only
- Maximum 20 lines
- Professional tone
- No fluff words

## Sections

Use these headings, in this order, and nothing else:

## Accomplishments

Work finished this week. One outcome per bullet.

## Blockers

What is stopping progress. Name the blocker and the impact. If there are none, write one bullet: `None`.

## Next week

Work committed for the coming week. One item per bullet.

## Rules

- Start with `## Accomplishments`. Do not add a title, summary, introduction, or closing.
- Put only bullets under each heading. No paragraphs, tables, or nested lists.
- Keep the whole report to 20 lines or fewer, including headings and blank lines.
- Use short, specific statements. State the outcome, the blocker, or the commitment.
- Omit filler, hedging, and praise. Do not use words such as "just", "really", "very", "excited", "great", "pleased", or "hopefully".
